# Design research and search visibility

Use for new public websites, substantial redesigns or requested SEO work. Small fixes skip fresh research. Preserve useful existing URLs, content and brand equity.

## Research a direction
Use the existing browser tooling to inspect a bounded selection of real sites. Start with supplied references, then typically two relevant competitors and one exceptional design reference. Search results and award galleries help discover candidates. Inspect the actual website on desktop and mobile before describing its visual execution. A screenshot or search snippet alone does not establish the booking flow or accessibility.
Record URLs, date, visitor goal, useful observations and proposed adaptations in a compact project note. Look at hierarchy, typography, spacing, image direction, navigation, proof, pricing clarity, calls to action and interaction states. Separate direct observation from inference. Extract principles and build an original client-specific design using approved/licensed assets. Avoid copying competitors' text, branding or images. Respect site access restrictions.
Translate Kyle's preference for Astra-quality design into observable choices: coherent art direction, strong composition, disciplined type and spacing, purposeful imagery, responsive behaviour and complete states. Use supplied examples when available. No specific look can be inferred solely from a model name.
Give designer a short synthesis, actual client assets and one direction. Research again only when evidence is missing or the brief changes. Keep useful source-linked references in the project for later work.

## Search strategy and content
Identify the customer's search intent, real service/product and actual geography. Map distinct customer needs to useful pages. Reuse existing analytics/Search Console evidence when authorised and available, otherwise label demand assumptions. Write clear, original answers grounded in real experience, products, services, case studies and approved facts. Use descriptive headings, page titles, URLs and internal links. Preserve important URLs or plan appropriate redirects when changing them.
For local businesses use consistent verified business details, real service areas, hours and contact information. Propose relevant Google Business Profile work separately when account action is needed. Only create location pages with genuinely distinct value and a real service relationship. Do not generate near-duplicate town pages, fabricated reviews, unsupported expertise claims or bulk low-value articles. Search rankings depend on many factors and cannot be guaranteed by configuration.

## Technical implementation
Check public routes for correct HTTP status, crawlable primary content and links, unique meaningful titles/descriptions, canonical selection, appropriate sitemap/robots rules, redirects and useful 404 behaviour. Verify rendered output for JavaScript-heavy sites. Keep private dashboards authenticated and excluded from public indexing. robots.txt is not access control. A crawl block can also prevent Google seeing a noindex directive, so select the indexing approach deliberately.
Use structured data supported by Google's current feature documentation and matching visible content and verified facts. Validate it with available tools. Do not invent ratings or promise rich results. Ensure sharing images and favicons resolve. Use responsive images, explicit dimensions, restrained scripts/fonts and usable interaction feedback. Measure page speed and accessibility with existing tooling and inspect mobile journeys.

## Launch and learn
Before an approved launch check actual production build output, important route status/content, indexing directives, canonical domain, sitemap, metadata, consent and conversion paths. Distinguish local checks from hosted checks. After launch use authorised Search Console/analytics data to check discovery, indexing and query/page performance and prioritise useful improvements. Record a baseline and review on request, without installing automatic model monitors. Treat ranking changes as measured outcomes over time.
