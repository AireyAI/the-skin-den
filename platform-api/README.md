# The Skin Den — platform-api

**Dedicated** Railway service for Rachel's studio. Do not deploy this for other clients.

- Railway project: `skin-den-platform`
- Public URL: `https://platform-api-production-3d5f.up.railway.app`
- Data volume: `/app/data` (SQLite) — Skin Den only
- Site admin: `https://theskinden.co.uk/admin/`
- Client account: `https://theskinden.co.uk/account/`

Treatment money still routes through **Clockwork Bookings** (`the-skin-den` merchant). This API owns client sign-in (Apple), CRM clients tab, and studio admin session.

Forked from the Kettle Kulture platform-api template; env + volume + Railway project are fully separate.
